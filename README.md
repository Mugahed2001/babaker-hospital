# مستشفى صالح بابكر الخيري — واجهة حديثة

واجهة ويب حديثة وأنيقة لمستشفى صالح بابكر الخيري، تعرض نفس محتوى الموقع الرسمي
وتجلب بياناته **مباشرةً وحيًّا** من الموقع الأساسي عبر واجهة WordPress REST API.

- المصدر: `https://babakerhospital.org/wp-json/wp/v2`
- لا توجد قاعدة بيانات ولا خادم — موقع ثابت (HTML/CSS/JS) يعمل على أي استضافة.

## الوظائف

| الصفحة | المصدر الحيّ |
|---|---|
| الرئيسية | الأقسام + آخر الأخبار |
| من نحن (`#/about`) | صفحة «من نحن» (page id 23) |
| الأقسام (`#/departments`) | الصفحات الفرعية لصفحة «الأقسام» (parent 32) |
| قسم مفرد (`#/department/:id`) | محتوى الصفحة |
| المركز الإعلامي (`#/news`) | منشورات تصنيف «الأخبار» (category 41) مع ترقيم صفحات |
| خبر مفرد (`#/news/:id`) | محتوى المنشور |
| تواصل معنا (`#/contact`) | نموذج عبر formsubmit.co + مواعيد العمل وروابط التواصل |

## التشغيل محليًا

> ⚠️ لا تفتح `index.html` بالنقر المزدوج (بروتوكول `file://`). المتصفح يمنع
> عندها جلب البيانات من الموقع الأساسي ويظهر تحذير أمني في الـ Console.
> شغّله عبر خادم محلي:

- **ويندوز:** انقر نقرًا مزدوجًا على `start.bat` — سيفتح المتصفح تلقائيًا.
- **يدويًا:**
  ```bash
  python -m http.server 8000
  # ثم افتح http://localhost:8000
  ```

بعد النشر على استضافة ثابتة (خطوة «النشر» أدناه) يعمل كل شيء دون أي إعداد.

## النشر

أي استضافة ملفات ثابتة (GitHub Pages / Netlify / Cloudflare Pages).
ملف `.nojekyll` موجود لـ GitHub Pages. التوجيه يعتمد على `#/` فلا يحتاج إعداد خادم.

## البنية

```
index.html            الهيكل + الترويسة + التذييل
assets/css/style.css   نظام التصميم (كوفي + بلِكس عربي، تركواز غامق + ذهبي)
assets/js/api.js       طبقة جلب البيانات من REST API + تنظيف المحتوى
assets/js/app.js       الموجّه + عرض الصفحات
assets/img/Toplogo.png شعار المستشفى الرسمي
```

## ملاحظات

- محتوى الأقسام مبني بمنشئ صفحات قديم؛ تُزال اختصاراته (`[mhc_*]`) عند العرض.
- الصور تُحمّل من نطاق المستشفى مباشرةً.
- واجهة REST API تُرسل ترويسات CORS تعكس أي أصل، فيعمل الجلب من المتصفح دون وسيط.
